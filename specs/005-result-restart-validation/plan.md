## Summary

Add a "Play Again" restart action to close the full game loop. When a round ends (`status === "ended"`), the host sees a "Play Again" button on `GamePage`; pressing it calls `POST /rooms/:code/restart`, which clears all round-specific state (word, strokes, guesses, timer, drawer) and transitions the room back to `"lobby"` while preserving all participants and cumulative scores. Non-host participants detect the transition via the existing 2-second polling loop and navigate to `/lobby` automatically. The `ResultPanel` empty-state message is updated to "No guesses were made." when a round ends with zero guesses. The `startGame` score initialisation is patched to preserve cumulative scores across restarts.

The result *display* (correct word reveal, scoreboard, guess history) is already fully implemented by the gameplay interaction feature and requires no changes.

## Data Flow

### Host Restarts the Game

```
GamePage (host, status === "ended")
  └─ onClick "Play Again"
       └─ roomStore.restartGame()
            └─ api.restartGame(code, participantId)          POST /rooms/:code/restart
                 └─ restartGameSchema.parse(body)
                 └─ restartGame(code, participantId)          store function
                      ├─ guard: room not found → 404
                      ├─ guard: participantId !== hostId → 403
                      ├─ guard: status !== "ended" → 409
                      ├─ room.status = "lobby"
                      ├─ room.currentDrawerId = null
                      ├─ room.secretWord = null
                      ├─ room.strokes = []
                      ├─ room.guesses = []
                      ├─ room.correctGuessers = []
                      ├─ room.roundStartedAt = null
                      └─ room.updatedAt = now()
                 ← 200 { room: RoomSnapshot (status: "lobby") }
            └─ setRoomSnapshot(response.room)
       └─ navigate('/lobby')      ← host navigated immediately
```

### Non-Host Detects Restart (polling path)

```
GamePage (non-host)
  └─ setInterval(fetchRoomSilent, 2000)      ← existing loop
       └─ GET /rooms/:code?participantId=...
            ← { room: { status: "lobby", gameState: null, ... } }
       └─ setRoomSnapshot(room)
  └─ useEffect on room?.status
       └─ if status === "lobby": navigate('/lobby')    ← new effect
```

### Score Preservation Across Restarts

```
round 1 ends:
  room.scores = { alice: 100, bob: 200 }

restartGame():
  room.scores unchanged = { alice: 100, bob: 200 }
  room.status = "lobby"

next startGame():
  for each participant:
    if !(id in room.scores): room.scores[id] = 0   ← only initialises new joiners
  → { alice: 100, bob: 200 }   ← preserved ✓
```
