## Summary

Wire the "Start Game" button to a new `POST /rooms/:code/start` endpoint. On success,
the room transitions from `lobby` → `playing`, the host becomes the drawer
(`currentDrawerId = hostId`), and the secret word is set deterministically to
`STARTER_WORDS[0]` ("rocket"). `GET /rooms/:code` returns `secretWord` only to the
drawer. Non-host participants auto-navigate from the lobby to `/game` via the existing
2s polling loop. The `GamePage` is rebuilt as a minimal, functional game-state display.
The `roles: ParticipantRole[]` array is removed from `RoomSnapshot`; role is derived
client-side from `participantId === currentDrawerId`.

## Data Flow

### Start Game (host path)

```
LobbyPage
  └─ onClick "Start Game"
       └─ roomStore.startGame(code, participantId)
            └─ api.startGame(code, participantId)          POST /rooms/:code/start
                 └─ startGameSchema.parse(body)            validates participantId present
                 └─ startGame(code, participantId)         store function
                      ├─ rooms.get(code.toUpperCase())
                      ├─ guard: not found → 404
                      ├─ guard: participantId ≠ hostId → 403
                      ├─ guard: status === "playing" → 409
                      ├─ room.status = "playing"
                      ├─ room.currentDrawerId = hostId
                      ├─ room.secretWord = STARTER_WORDS[0]
                      └─ rooms.set(code, room)
                 ← 200 { room: toRoomSnapshot(room, participantId) }
            └─ setRoomSnapshot(response.room)
       └─ navigate("/game")
```

### Non-host auto-navigate (polling path)

```
LobbyPage
  └─ useEffect: setInterval(fetchRoomSilent, 2000)
       └─ fetchRoomSilent() → setRoomSnapshot(room)
  └─ useEffect [room?.status]: if room.status === "playing" → navigate("/game")
```

### Secret word visibility in toRoomSnapshot

```
toRoomSnapshot(room, viewerParticipantId):
  secretWord = (status === "playing" && viewerParticipantId === currentDrawerId)
               ? room.secretWord
               : null
  currentDrawerId = room.currentDrawerId  // always returned when playing
  // roles field removed entirely
```
