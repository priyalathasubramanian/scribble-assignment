# Implementation Plan: Gameplay Interaction

**Branch**: `004-gameplay-interaction` | **Date**: 2026-06-03 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-gameplay-interaction/spec.md`

---

## Summary

Add full gameplay interaction to the Scribble game: the drawer gets a `<canvas>` to draw/clear on; strokes are persisted in-memory as `Stroke[]` and delivered to guessers via the existing 2s polling loop. Guessers submit text guesses via `POST /rooms/:code/guess`; the server trims first, then case-insensitively compares against the secret word, scores correct guesses +100, and locks out guessers after a correct guess (disabled form + "You already guessed correctly!"). A 60-second round timer is enforced lazily (check-on-access) — no background process. When the round ends, `secretWord` is revealed to all players (not just the drawer) via the same polling snapshot. `GET /rooms/:code` gains a `gameState` field carrying strokes, guesses, scores, and `roundEndsAt`. The `GamePage` shows a round-over banner with the secret word when `status === "ended"`. The `GuessForm`, `Scoreboard`, and `ResultPanel` components are fully wired. Polling failures are silent — clients retain last known state and retry on the next interval.

**Language/Version**: TypeScript 5.x / Node.js 18+ (backend); TypeScript 5.x / React 18 (frontend)

**Primary Dependencies**: Express 4.x + Zod (backend); React Router v6 + `useSyncExternalStore` (frontend)

**Storage**: In-memory `Map<string, Room>` — no persistence

**Testing**: Vitest (both backend and frontend)

**Target Platform**: Local development server only

**Project Type**: Web application (Express API + Vite/React SPA)

**Performance Goals**: Guess response < 200ms; draw stroke response < 100ms; polling detects state change within 2s

**Constraints**: In-memory only; no auth; no WebSockets; no new dependencies; timer is check-on-access (no background process)

**Scale/Scope**: 2–10 players per room; single round; single server

## Data Flow

### Drawer Submits a Stroke

```
GamePage (drawer)
  └─ <canvas> onMouseUp
       └─ collectStroke() → { points: [{x,y}, …] }
            └─ roomStore.addStroke(code, participantId, stroke)
                 └─ api.addStroke(code, participantId, stroke)    POST /rooms/:code/draw
                      └─ addStrokeSchema.parse(body)
                      └─ addStroke(code, participantId, stroke)   store function
                           ├─ checkRoundExpiry(room)
                           ├─ guard: not found → 404
                           ├─ guard: not drawer → 403
                           ├─ guard: status !== "playing" → 409
                           └─ room.strokes.push(stroke)
                      ← 200 { ok: true }
```

### Drawer Clears Canvas

```
GamePage (drawer)
  └─ onClick "Clear"
       └─ roomStore.clearCanvas(code, participantId)
            └─ api.clearCanvas(code, participantId)              POST /rooms/:code/clear
                 └─ clearCanvas(code, participantId)             store function
                      ├─ checkRoundExpiry(room)
                      ├─ guard: not drawer → 403
                      ├─ guard: status !== "playing" → 409
                      └─ room.strokes = []
                 ← 200 { ok: true }
```

### Guesser Submits a Guess

```
GamePage (guesser)
  └─ <GuessForm> onSubmit(text)
       └─ roomStore.submitGuess(code, participantId, text)
            └─ api.submitGuess(code, participantId, text)        POST /rooms/:code/guess
                 └─ submitGuessSchema.parse(body)               trim + non-empty validation
                 └─ submitGuess(code, participantId, text)       store function
                      ├─ checkRoundExpiry(room)
                      ├─ guard: room not found → 404
                      ├─ guard: participantId === currentDrawerId → 403
                      ├─ guard: status !== "playing" → 409
                      ├─ guard: correctGuessers.includes(id) → 409
                      ├─ isCorrect = trimmed.toLowerCase() === secretWord.toLowerCase()
                      ├─ room.guesses.push({ participantId, text: trimmed, isCorrect, submittedAt: now() })
                      ├─ if isCorrect: room.scores[participantId] += 100; room.correctGuessers.push(participantId)
                      └─ return guess
                 ← 200 { guess: { participantId, text, isCorrect, submittedAt } }
```

### All Players Sync State (polling path)

```
GamePage
  └─ useEffect: setInterval(fetchRoomSilent, 2000)
       └─ GET /rooms/:code?participantId=...
            └─ toRoomSnapshot(room, viewerParticipantId)
                 ├─ checkRoundExpiry(room)        ← lazy timer transition
                 ├─ secretWord exposed to drawer always; exposed to ALL when status === "ended"
                 └─ gameState = {
                      roundEndsAt, strokes, guesses,
                      scores: participants.map(p => ({ participantId: p.id, score: room.scores[p.id] })),
                      correctGuessers
                    }
            ← { room: RoomSnapshot }   (includes gameState)
       └─ setRoomSnapshot(room)
  └─ GamePage re-renders canvas, scoreboard, guess feed from room.gameState
```

### Round Timer — check-on-access

```
checkRoundExpiry(room: Room): void
  if room.status !== "playing": return
  if Date.now() >= new Date(room.roundStartedAt).getTime() + room.roundDurationSeconds * 1000:
    room.status = "ended"
    room.updatedAt = now()
    rooms.set(room.code, room)
```

Called at the start of `submitGuess`, `addStroke`, `clearCanvas`, and `toRoomSnapshot`.
